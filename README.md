An AI talking interface demo

I caught an episode of the Gerry Anderson classic UFO series. It features a golf ball typewriter as part of the opening credits, which made me think what a modern version might look like if it was made today.
A modern version would probably be a AI interface that alerts the SHADO team to leap into their miniskirts. 

This demo works on either the microphone or will play a mp3 file. It works best with Audio books.

You'll need to play with the colours if your system is slow; the rainbow default is very cpu intensive. If it's too slow, press the 2 or 3 key. You'll also need to use the arrow keys to set the sensitivity and acceleration curves for your sample audio and system.

The frequency mode changes the 0s and 1s dynamically as the frequency changes.

This needs further work but is a minimal viable product testing out the idea. Let me know if you improve upon the design.
